# genome PDAC2026

Current collaborator code for the pancreatic cancer multi-omics study, organized
by analysis and linked to the figures and tables it supports.

The public repository contains source code, configuration templates and method
documentation only. Patient data, results, figures and manuscript files remain
private. No study code was executed during this reorganization.

its input. Rendering code is distinguished from statistical analysis. Missing
code is documented rather than replaced with an unrelated earlier workflow.
