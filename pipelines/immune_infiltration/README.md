# Immune And Stromal Infiltration

This folder contains reusable, data-safe code for paired tumour-normal analysis
of immune and stromal deconvolution outputs.

The manuscript used immune/stromal score tables generated by ESTIMATE,
MCP-counter, CIBERSORT LM22, EPIC, xCell and quanTIseq. These tools produce
method-specific scores or fractions, so the outputs should not be combined as
percentages. Each method was interpreted on its own scale.

## Paired Tumour-Normal Comparison

Use `paired_tumour_normal_immune_comparison.R` when you already have a
deconvolution score matrix and sample metadata.

Expected score matrix:

```text
feature    01N_RNA    01T_RNA    02N_RNA    02T_RNA
T cells    ...        ...        ...        ...
Fibroblast ...        ...        ...        ...
```

Expected metadata:

```text
sample_id  patient_id  condition
01N_RNA    01          Normal
01T_RNA    01          Tumour
02N_RNA    02          Normal
02T_RNA    02          Tumour
```

Run:

```bash
Rscript paired_tumour_normal_immune_comparison.R \
  scores.tsv \
  metadata.tsv \
  results/immune_method_name \
  cell_type
```

The script calculates tumour-minus-normal deltas for each patient and feature,
then runs paired Wilcoxon signed-rank tests and paired t-tests feature by
feature. It applies Benjamini-Hochberg FDR correction across features within the
method. The manuscript separates nominal paired trends from FDR-significant
features for this reason.

## Interpretation Used In The Manuscript

Across the PDAC cohort, the paired tumour-normal immune analyses showed
concordant nominal trends toward higher fibroblast/stromal or macrophage-like
signals in tumours and lower lymphoid/B-cell-related signals in tumours.
However, individual features did not remain significant after FDR correction,
so the manuscript treats the immune-infiltration result as exploratory and
directional rather than definitive.
